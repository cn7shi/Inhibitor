# Inhibitor (抑制器)

> **专治 Agent 的“赛博精神病”。**
> Inhibitor 是一个专为大模型应用设计的运行时神经抑制器。当你的 Agent 因为挂载过多工具、被复杂报错撑爆上下文而即将“发疯”时，Inhibitor 会在底层强行注入工程化约束，锁死它的理智。

放弃 Prompt 祈祷，回归系统工程。Inhibitor 致力于解决大模型落地时的不可控暴走问题，提供坚实的控制底座：

* 🛡️ **建立硬约束，告别“祈祷式”控制**
  不再依赖脆弱的 Markdown 格式或 Prompt 话术去“乞求”模型听话。在 Agent 和 LLM 之间构建物理级的系统硬约束，相当于给模型装上不可违背的底层协议锁。

* 🚧 **错误隔离与上游消化（阻断上下文污染）**
  **我们认为：报错信息对模型单次纠错有效，但对全局上下文是致命的神经毒素。** Inhibitor 将错误处理逻辑上游化，在底层拦截并消化异常，彻底阻断错误的“爆炸半径”，确保只将纯净的结果返还给 Agent。

* 📉 **独创 SAN 值（理智值）负反馈系统**
  实时监控 Agent 的“精神状态”。当遭遇劣质指令、环境异常或陷入报错死循环时，模型会持续“掉 SAN”。告别黑盒盲猜，让系统的混乱程度与健康度实时可度量。

* 🔒 **根源级权限物理阻断**
  严格收束 LLM 权限。从物理根源彻底禁止大模型在理智不稳定时执行越权操作或危险动作。

* 🤝 **SAN 值归零熔断与人类接管**
  拒绝死循环与胡言乱语。当 Agent 的 SAN 值跌破警戒线（赛博精神病发作/无法自动恢复异常）时，系统会果断触发熔断机制，强制切断运行，并呼叫人类（Human-in-the-loop）介入接管。
